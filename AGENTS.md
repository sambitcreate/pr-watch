# pr-watch

Agent-facing rules for this repository (and any repo that installs the
pr-watch skill). If you are an AI coding agent asked to watch, babysit,
monitor, or wait on a pull request: read `SKILL.md` and follow its decision
order. The one-sentence version:

> Waiting is a shell's job, fixing is yours — never poll, sleep, or block
> inside your own turn.
